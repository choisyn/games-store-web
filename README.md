# games-store-web
web games mall/网页游戏商城/模板商城

### 后端
- **Spring Boot 3.2.0** - 主框架
- **Spring Data JPA** - 数据持久化
- **Spring Web** - Web开发
- **MySQL 8.0** - 关系型数据库
- **Thymeleaf** - 服务端模板引擎
- **Hikari** - 数据库连接池

### 前端
- **Bootstrap 5.3** - 响应式UI框架
- **Bootstrap Icons** - 图标库
- **原生JavaScript** - 前端交互
- **Thymeleaf** - 模板渲染

### 开发工具
- **Maven** - 项目构建
- **JDK 23** - Java开发工具包
- **Git** - 版本控制
